# Retail Sales Intelligence & Business Analysis

## Project Overview
This project analyzes online retail transaction data to identify sales trends, customer purchasing behavior, product performance, and business opportunities.

The objective is to transform raw retail data into meaningful business insights and actionable recommendations using data analytics tools.

## Dataset
- Source: UCI Machine Learning Repository
- Dataset: Online Retail
- Original Records: 541,909
- Original Columns: 8
- Time Period: December 2010 – December 2011

## Tools and Technologies
- Microsoft Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL Server
- Power BI

## Project Workflow
1. Dataset Download
2. Data Understanding
3. Data Quality Audit
4. Data Cleaning
5. Exploratory Data Analysis (EDA)
6. SQL Analysis
7. Data Verification
8. Power BI Visualization
9. Business Recommendations

## Data Cleaning
- Original records: 541,909
- Duplicate records removed: 5,268
- Final records: 536,641
- Exact duplicate records remaining: 0

Missing values and unusual transactions were investigated and handled carefully. Missing customer information was retained where appropriate for transparency.

## Key Business Results
- Total Sales: £10,642,110.80
- Total Orders: 19,960
- Average Order Value: £533.17
- Identifiable Customers: 4,338
- Repeat Customers: 2,845
- Repeat Customer Rate: 65.58%
- Cancellation Rate: 16.12%

## Power BI Dashboard
The interactive dashboard includes:

- Total Sales

- Total Customers

- Non-Cancelled Orders Percentage
- Monthly Sales Trend
- Sales by Top Countries
- Top Products by Sales
- Top Customers by Sales
- Country and Date Filters

## Key Insights
1. The United Kingdom is the largest sales market.
2. Repeat customers represent 65.58% of identifiable customers.
3. A small group of products contributes significantly to sales.
4. Cancellations represent an opportunity for further investigation.
5. Monthly sales trends support better business planning.

## Business Recommendations
- Strengthen the UK market.
- Improve inventory planning.
- Increase customer retention.
- Investigate and reduce avoidable cancellations.
- Use historical sales trends for better planning.

## Project Limitations
- Some transactions have missing CustomerID values.
- Historical transaction data does not explain the reasons for cancellations.
- The dataset does not contain actual delivery status.
- Findings describe the available historical data and do not guarantee future performance.

## Conclusion
This project demonstrates an end-to-end retail analytics workflow, from raw data inspection and cleaning to SQL analysis, Power BI visualization, and business recommendations.

It demonstrates practical skills in data preparation, exploratory analysis, database querying, data visualization, and business decision support.
